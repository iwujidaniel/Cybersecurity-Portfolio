# Wireshark Network Traffic Analysis

## Project Overview
This project demonstrates the use of Wireshark to capture and analyze live network traffic in a Kali Linux virtual machine.

## Objectives
- Capture live packets from the network interface.
- Analyze ICMP (Ping) traffic.
- Analyze ARP traffic.
- Apply Wireshark display filters.
- Save captured traffic for future analysis.

## Tools Used
- Kali Linux
- Wireshark
- VirtualBox

## Activities Performed
- Started packet capture on the eth0 interface.
- Generated ICMP traffic using the ping command.
- Captured ICMP Echo Request and Echo Reply packets.
- Applied the icmp display filter.
- Applied the arp display filter.
- Saved the capture as a .pcapng file.

## Skills Demonstrated
- Network Packet Capture
- Protocol Analysis
- ICMP Analysis
- ARP Analysis
- Wireshark Filtering
- Traffic Documentation

## Files Included
- Packet capture (.pcapng)
- Screenshots
- Analysis report

## Outcome
Successfully captured, filtered, and analyzed live network traffic using Wireshark and documented the findings for a cybersecurity portfolio.
