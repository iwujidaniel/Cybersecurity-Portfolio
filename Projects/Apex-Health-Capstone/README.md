# Apex Healthcare Cybersecurity Capstone Project

## Project Overview

This repository contains our TS Academy Cybersecurity Capstone Project, which focused on assessing the security posture of a legacy healthcare environment.

The project involved identifying vulnerabilities, evaluating their risks, recommending security controls, and proposing Governance, Risk, and Compliance (GRC) policies to improve the organization's cybersecurity posture.

> Note: This was a collaborative team project. The final report combines findings contributed by different team members into a single professional security assessment report.

---

## Objectives

- Assess legacy systems for security weaknesses
- Identify vulnerabilities affecting critical services
- Evaluate risks using a qualitative risk assessment
- Recommend technical security controls
- Develop GRC policy recommendations

---

## Systems Assessed

- Kioptrix
- Metasploitable 2

---

## Tools Used

- Kali Linux
- Nmap
- Nessus Essentials
- VirtualBox
- Microsoft Word

---

## Major Vulnerabilities Identified

- Samba Badlock
- Unencrypted Telnet Server
- RSH Service Detection
- Buffer Overflow
- Weak Cipher Suite
- Privilege Escalation

---

## Risk Assessment

Risks were evaluated using:

- Likelihood
- Impact
- Risk Rating

Ratings used:

- High
- Medium
- Low

---

## Security Controls Recommended

- Upgrade vulnerable software
- Disable insecure services
- Replace Telnet with SSH
- Restrict user privileges
- Apply regular security patches
- Implement Endpoint Detection and Response (EDR)

---

## GRC Policies Recommended

- Patch Management Policy
- Access Control Policy
- Vulnerability Management Policy
- Acceptable Use Policy
