Detection Scenario:
Detect PowerShell spawning another PowerShell process.

Telemetry Source:
Sysmon Operational Log

Event ID:
1 — Process Create

Detection Indicators:
- Image: powershell.exe
- ParentImage: powershell.exe
- IntegrityLevel: High
- CommandLine contains PowerShell execution parameters

Controlled Test:
powershell.exe -NoProfile -Command
"Write-Output 'Project7-Detection-Test'"

Result:
Detection condition observed successfully.

Initial Alert:
Suspicious PowerShell process chain.

Investigation:
The command was deliberately generated as part of the Project 7
controlled test.

Final Disposition:
Benign / authorized test activity.

SOC Lesson:
Detections should identify potentially suspicious behavior but
analysts must investigate the surrounding context before declaring
an event malicious.

RESPONSE ACTION

Alert:
PowerShell spawned another PowerShell process.

Initial Response:
The event was validated using Sysmon Event ID 1.

Investigation Actions:
1. Identified the process and PID.
2. Identified the initiating user.
3. Reviewed the command line.
4. Examined the parent process.
5. Reviewed integrity level.
6. Correlated related Sysmon telemetry.
7. Determined the activity was part of an authorized controlled test.

Final Response:
No containment or remediation was required because the activity was
confirmed as benign.

If this were confirmed malicious in a production environment,
appropriate response actions could include isolating the affected
endpoint, preserving evidence, terminating the malicious process,
blocking related indicators, escalating the incident, and documenting
the incident according to organizational procedures.
