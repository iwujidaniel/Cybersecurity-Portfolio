# Apex Healthcare Security Assessment (Capstone Project)

## Project Overview

This project was completed as part of the TS Academy Cybersecurity Capstone.

The assessment focuses on identifying security vulnerabilities in legacy healthcare systems, evaluating associated risks, and recommending appropriate security controls to improve the organization's security posture and compliance.

---

## Objectives

- Identify system vulnerabilities
- Perform risk assessment
- Recommend security controls
- Improve compliance with cybersecurity best practices

---

## Environment

- Kali Linux
- Kioptrix
- Metasploitable 2
- Nessus Essentials
- Nmap
- VirtualBox

---

## Activities Performed

- Network Discovery
- Port Scanning
- Service Enumeration
- Vulnerability Identification
- Risk Assessment
- Security Recommendations

---

## Key Findings

### Kioptrix

- Samba Vulnerability
- Telnet Service Enabled
- RSH Service Detected

### Metasploitable 2

- Multiple Open Ports
- FTP Vulnerabilities
- SMB Weaknesses
- Outdated Services
- Web Application Vulnerabilities

---

## Deliverables

- Security Assessment Report
- Vulnerability Scan Results
- Supporting Screenshots
- Risk Assessment
